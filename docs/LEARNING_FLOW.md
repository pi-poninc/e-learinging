# スムーズに「pipon流の働き方」を学べる導線

受講者が迷わず・続けられる学習体験にするための構成と、有効化手順。

## 1. 王道ジャーニー（まずここから）

迷ったらこれ、という一本道を用意しました。
**「pipon流の働き方 ― 王道ジャーニー【まずここから】」**（`/journey` の先頭）

基礎（会社の基本）→ 道具（Claude Code）→ 設計の型（現場起点／要求と設計）→
実務例（紙・FAX自動化）→ 案件を回す（受託PM／炎上しない定例）→ 商売の型（FDEスクール）→
顧客（WS）→ 判断（案件追体験）→ 知的生産（第二の脳）。

- すべての公開講座を、いずれかのロードマップに所属させ、**行き止まり（迷子講座）をゼロ**にしました。
  - 王道のほか、「実務・設計の引き出し（リファレンス）」「製造業 × AI 入門」を用意。
- 作成SQL: `content/path_pipon_way.sql`（可逆: `_revert.sql`）。
- 講座の順番・目標日・束ね直しは管理画面「学習ロードマップ」(`/admin/paths`) から編集可。

## 2. ダッシュボードの「次の一歩」

ログイン直後のダッシュボード最上部に、王道ジャーニーの**次にやる1本**を大きく表示します
（`components/next-step-card.tsx`、`/api/journey` を利用）。

- 未開始 → 「王道ジャーニーを始める」CTA。
- 進行中 → 「次はこれ：◯◯」＋この講座を続けるボタン＋全体進捗バー。
- 完走 → 「pipon流 修了認定」の金色バッジ（下記）。

## 3. 「pipon流 修了」認定バッジ

王道ジャーニーを100%完走すると、ダッシュボードに**金色の修了認定バッジ**が出ます。
既存のFDEレベル（`/journey`）や講座ごとの修了証（`/admin/certificates`）と併用できます。

## 4. 続ける仕組み（習慣化エンジン）＝ 要・有効化

「スムーズに続ける」ための本命。**実装済みだが既定OFF**。本番で有効化すると効きます。

### 有効化手順（Render 環境変数）
```
FEATURE_SUBMISSION_REVIEW=true        # 毎日提出 × 人の添削（習慣化）
NEXT_PUBLIC_FEATURE_SUBMISSION_REVIEW=true   # 受講者ナビに「練習（提出）」を表示
# リマインドを自動で送るなら（DEPLOY.md 参照）
CRON_SECRET=（自動生成）
RESEND_API_KEY=（Resendのキー）
```
- 受講者は毎日ミニ提出 → スタッフ/ピアが添削 → 継続が可視化され、離脱しにくくなる。
- リマインドCron（`/api/cron/reminders`・毎日JST9時）が、期限が近い/過ぎた受講者へ自動通知。
- 詳細は `DEPLOY.md`（環境変数・フラグ・Cron）。

### おすすめの段階投入
1. まず王道ジャーニー＋ダッシュボード導線（デプロイするだけで有効）。
2. 次に `FEATURE_SUBMISSION_REVIEW` と リマインド（RESEND_API_KEY）で習慣化。
3. 慣れたら スキルマップ/ピアレビュー/AIコーチ等の育成フラグを順に。

## まとめ

- **道**：王道ジャーニーで迷わせない（迷子講座ゼロ）。
- **入口**：ダッシュボードが次の1本を押し出す。
- **到達**：完走バッジ＋FDEレベル＋修了証で可視化。
- **継続**：習慣化エンジン（提出×添削＋リマインド）をONにする。← ここが伸びしろ。
