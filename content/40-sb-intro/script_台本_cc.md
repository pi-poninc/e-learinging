# 第二の脳の作り方 第1回 第二の脳とは何か — ナレーション台本

行数（9行）= スライド枚数（9枚）に一致させること。

| # | スライド | ナレーション |
|---|---|---|
| 1 | タイトル | 第二の脳の作り方、第1回です。今日はまず、第二の脳とは何か、そしてなぜ、もう一つの脳を持つのか、というお話をします。難しい準備はいりません。考え方だけ、持ち帰ってください。 |
| 2 | 悩み | こんな悩み、ありませんか。メモはするのに、あちこちに散らばって、どこに書いたか分からない。書いたこと自体を忘れて、同じことを何度も調べ直す。振り返りたいのに、過去の情報がつながっていない。実はこれ、記憶を全部、自分の頭だけで抱えようとするから起きます。 |
| 3 | 第二の脳とは | そこで、第二の脳です。これは、頭の外に記憶を預けて、いつでも引き出せるようにする仕組みのことです。必要なときにすぐ検索でき、貯めた知識どうしがつながって、考えるのを助けてくれる。脳は、覚えることから解放されて、考えることに集中できます。 |
| 4 | 2つの役割 | このコースで作る第二の脳には、役割が2つあります。読む・書くのが、オブシディアンというノートアプリ。集めたり、分析したり、作ったりして動かすのが、エーアイ、クロードコードです。オブシディアンは静かな図書館、エーアイはそこで働く司書、とイメージすると分かりやすいです。 |
| 5 | 違い | 普通のメモ帳と、何が違うのか。従来のメモは、手で書いて貯めて、書いたら忘れて、情報はバラバラでした。この第二の脳は、データが自動で流れ込み、すぐに検索・分析でき、リンクで全部がつながります。静かなメモ帳から、生きた知識へ。これが目指すところです。 |
| 6 | 全体像 | 育て方は、4つのステップです。一つ、ためる。思いついたことを、まず全部放り込む。二つ、まわす。毎日、軽く見返す習慣をつくる。三つ、つなげる。情報を、自分の言葉の知識に変える。四つ、生かす。エーアイとデータ連携で、自動で動く脳にする。 |
| 7 | 安心 | 身構えないでください。最初は、オブシディアンとフォルダだけで大丈夫です。無料のアプリを入れて、フォルダを5つほど作って、メモを放り込むところから。エーアイやデータ連携は、慣れてきてから足せばいい。いきなり全部は、やりません。 |
| 8 | 進み方 | このコースは、土台から順に進みます。第2回で土台、つまりフォルダ構成。第3回と第4回で、ためる・まわす、という習慣。第5回で、つなげる、という知識化。そして第6回と第7回で、エーアイで生かす、続ける。誰でも、第2回から手を動かせます。 |
| 9 | まとめ | 第1回のまとめです。第二の脳とは、外に知識を貯めて、すぐ引き出せる仕組み。読むのはオブシディアン、動かすのはエーアイ。そして、まずは小さく始める。今日はこの考え方だけ、持ち帰ってください。次回から、一緒に手を動かしていきましょう。 |
