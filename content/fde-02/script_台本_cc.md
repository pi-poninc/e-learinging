# FDEスクール 第2話「課題一覧の作り方」台本

> スライド番号 × ナレーション（`video-elearning-compose` 用）。約6分。出典 [[FDEの型]]②。

| # | スライド（画面の要点） | ナレーション（肉声） |
|---|---|---|
| 1 | タイトル「課題一覧の作り方」/ FDEスクール 第2話 | FDEスクール第2話、「課題一覧の作り方」。月額の“燃料”になる、課題のリストをどう作るかです。 |
| 2 | 見出し「狙い」/ 「次に月額でやる5つ」を顧客と合意できる状態に | 狙いは1つ。次に月額で解く課題を5つ、お客さまと合意できる状態にすることです。これができれば、月額提案は自然に通ります。 |
| 3 | 手順1 / 訪問・観察で業務を洗う（Slack・Drive・定例も棚卸し） | 手順1、訪問と観察。現場で業務を洗います。Slackやドライブ、これまでの定例の記録も棚卸しして、情報を全部集めます。 |
| 4 | 手順2 / 課題を“粗く全部”出す（遠慮しない） | 手順2、課題を粗く全部出す。ここでは遠慮しません。小さいものも、難しそうなものも、いったん全部並べます。 |
| 5 | 手順3 / 効果 × 着手の容易さ で優先度 | 手順3、優先度付け。それぞれの課題を「効果の大きさ」と「着手のしやすさ」の2軸で見ます。効果が大きく、すぐ着手できるものが最優先です。 |
| 6 | 手順4 / 5つ前後に“束ねる” | 手順4、5つ前後に束ねます。多すぎると月額提案が重くなります。テーマでまとめて、5つくらいに絞ります。 |
| 7 | 手順5 / 定例でローリング更新 | 手順5、更新です。課題一覧は作って終わりではありません。毎回の定例で見直し、終わったものは次の課題に差し替える。これがローリングです。 |
| 8 | ONS例 / 3本柱に束ねた：ポータル / 人事評価 / TA選別 → 各PRに分解 | 実例です。大阪鉛さんでは、たくさんの課題を3本柱に束ねました。社内ポータル、人事評価、そしてTA選別。さらに各テーマを、具体的な作業単位に分解して進めています。 |
| 9 | テンプレ / 表「# / 課題 / 効果 / 容易さ / 月額に入れる / 備考」 | 使うのはこのテンプレートです。課題、効果、容易さ、月額に入れるか、備考。この表を埋めれば、そのまま次回の月額提案になります。 |
| 10 | クロージング / 次回「第3話 月額提案の出し方」 | 課題が5つ揃ったら、いよいよ提案です。次回は第3話、「月額提案の出し方」。 |
