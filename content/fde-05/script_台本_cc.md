# FDEスクール 第5話「共通の道具」台本

| # | スライド | ナレーション |
|---|---|---|
| 1 | タイトル「共通の道具」/ 第5話 | FDEスクール第5話、「共通の道具」。FDEの3条件の、一番見落とされがちな3つ目です。 |
| 2 | なぜ重要 / 無いと「人貸し」に戻る | なぜ重要か。共通の道具が無いと、ただ人を貸すだけの会社に戻ってしまいます。これがあるから、早く安く提供できます。 |
| 3 | 道具の種類 / スキル・手順書・接続部品 | 道具は3種類。Claude Codeのスキル。案件ごとに残す手順書。そして、どの顧客でも使える接続部品です。 |
| 4 | 製品化した道具 / ボイスチャート・portal雛形・選別モデル | 道具が育つと製品になります。医療のボイスチャート、社内ポータルの雛形、大阪鉛で作った選別モデル。現場から生まれています。 |
| 5 | 循環 / 現場 → 道具 → 次の顧客 | 大事なのは循環です。現場で作ったものを必ず道具として残し、次の顧客で使い回す。これで会社に資産が積み上がります。 |
| 6 | 置き場 / pipon・GitHub・第二の脳 | 置き場も決めておきます。piponのイントラ、GitHub、そしてこの第二の脳。誰でも見つけて再利用できる状態にします。 |
| 7 | まとめ / 次回「第6話 ケース: ONS」 | 道具がそろえば、FDEは加速します。最終回は第6話、実例の大阪鉛を通しで見ます。 |
