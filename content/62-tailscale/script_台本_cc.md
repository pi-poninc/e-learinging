# Tailscaleで自宅Macをサーバー化 — 台本

行数（16行）= スライド枚数（16枚）。pptxのスライド本文とノートの意図から、読み上げ用に書き起こし（URL・出典・制作メモは除外）。

| # | スライド | ナレーション |
|---|---|---|
| 1 | タイトル | 外出先のスマホから、自宅MacのAIに仕事を振る。テイルスケールとエスエスエイチ、そしてクロードコードやコーデックスを組み合わせて、外から自宅のMacのAIに、安全に仕事を頼める仕組みを作ります。 |
| 2 | こんな悩み | こんな悩みはありませんか。移動中にAIに頼みたい。でも外ではPCを開けず、手元にあるのはスマホだけ。そしてAIは自宅のMacにいる。使いたい場所と、AIが動いている場所がずれているんです。だったら、自宅のMacを外から安全に使えるようにすればいい。これが今日のテーマです。 |
| 3 | 全体像 | 全体像です。外出先のスマホやPCから、テイルスケールという安全なトンネルを通って、自宅のMacにエスエスエイチでログインします。Macの中では、ティーマックスという作業場で、クロードコードやコーデックスが働く。テイルスケールが端末どうしを直接つなぐので、ルーターのポート開放は一切しません。 |
| 4 | 部品の役割 | 部品は5つです。テイルスケールは、端末どうしを暗号化でつなぐ私設の網。エスエスエイチは、外からMacのターミナルに安全に入る仕組みで、Macに標準で入っています。ティーマックスは作業場を保持し、接続が切れてもAIを動かし続け、あとで戻れる。そしてクロードコードとコーデックスが、ターミナルで動くAIです。どちらか一方でも構いません。今は覚えなくて大丈夫、次から順に入れていきます。 |
| 5 | Mac側① スリープしない | ここからMac側の設定、4つです。まずは、Macがスリープしないようにします。外から呼んでも、Macが寝ていては応答できないからです。デスクトップ型なら、システム設定のエネルギーで、ディスプレイがオフのときに自動でスリープさせない、をオン。停電に備えて、停電後に自動的に起動、もオンにします。ノート型なら、バッテリーのオプションで同じ設定をし、電源アダプタをつないだままにします。 |
| 6 | Mac側② リモートログイン | 2つ目、リモートログインをオンにします。システム設定の、一般、共有、リモートログイン、のスイッチをオン。これでMacが、外からのエスエスエイチ接続を受け付ける状態になります。許可するユーザーは、すべてのユーザではなく、次のユーザのみ、にして、自分のアカウントだけを登録。入口は、できるだけ狭くしておきます。 |
| 7 | Mac側③ Tailscale導入 | 3つ目、Macにテイルスケールを入れます。公式サイトからMac版をダウンロードし、初回起動で出るダイアログで、ブイピーエヌ構成の追加を許可。あとは、グーグルやマイクロソフト、ギットハブなどのアカウントでサインインします。入れ終わると、このMacに、住所と名前が割り当てられ、名前で接続できるようになります。メニューバーにアイコンが出れば完了。住所と名前を控えておきましょう。 |
| 8 | Mac側④ AIとtmux | 4つ目、AIのコマンド版とティーマックスを入れます。クロードコードは、公式のインストールコマンドを一行、ターミナルに貼り付け、入れたらクロードと打ってブラウザでログイン。コーデックスも同じように、コマンドで入れて、コーデックスと打ってチャットジーピーティーでサインイン。ティーマックスは、Homebrewが入っていれば、ブリュー・インストール・ティーマックスの一行で入ります。AIはどちらか一方でも構いません。 |
| 9 | 端末側① Tailscale | ここから端末側、3つです。まず、スマホやPCにもテイルスケールを入れます。iPhoneやAndroidはアプリストアから、外で使うPCは公式サイトから。ポイントは、Macと同じアカウントでログインすること。同じアカウントに入った端末どうしが、ひとつの私設の網になります。 |
| 10 | 端末側② SSHアプリ | 2つ目、エスエスエイチアプリを用意します。スマホなら、定番のターミウスが便利です。無料プランがあり、接続先と鍵を登録しておけます。PCは標準のターミナルでかまいません。Macはターミナル、ウィンドウズはパワーシェル。どちらも、エスエスエイチコマンドが最初から使えます。基本、追加で買うものはありません。 |
| 11 | 端末側③ 鍵で入る | 3つ目、パスワードではなく、鍵で入ります。鍵は、外に出さない秘密鍵と、渡してよい公開鍵のペアです。手元の端末で鍵のペアを作り、公開鍵だけをMacに登録します。パスワードは、盗まれれば誰でも入れてしまいますが、鍵なら、秘密鍵を持つ端末からしか入れません。 |
| 12 | 接続テスト | 最後に、接続テストです。まず、エスエスエイチで、ユーザー名、アットマーク、Macの名前、と打ってMacに入る。次に、ティーマックスで、エーアイという作業場を開きます。あれば戻り、なければ作られます。そしてクロードと打ってAIを起動。コーデックスでも大丈夫です。必ずWiFiを切って、モバイル回線でも入れることを確認しましょう。名前で入れなければ、住所で試します。 |
| 13 | 実際の使い方 | 実際の使い方の流れです。テイルスケールをオンにしてエスエスエイチで接続し、作業場に戻って、AIに調べものやまとめを頼む。あとは、アプリを閉じて移動してかまいません。AIは動き続けます。着いたら再接続すれば、結果が待っています。頼んで、切って、あとで見る。スマホを見続ける必要はありません。 |
| 14 | メリット | この仕組みのメリットです。ポート開放が不要で、外部に入口を作らないので安全。自宅Macのファイルも、入れてあるツールも、そのまま使えます。端末も選ばず、テイルスケールとエスエスエイチが使えれば何でもよい。そして、ティーマックスのおかげで、回線が切れてもAIの作業は止まりません。 |
| 15 | 注意点とセキュリティ | 注意点とセキュリティです。入口はテイルスケールだけにして、ルーターのポート開放や、どこからでもエスエスエイチ、は作らない。パスワードは使わず、鍵で入る。慣れたら、パスワードログインを無効にすると、より安全です。停電やスリープ、回線が切れれば、当然つながりません。またテイルスケールの端末認証は、既定で180日。切れたら、Macで再ログインします。 |
| 16 | まとめ | まとめます。家のMacを、どこからでも使えるAIの作業場にする。設定は、Mac側が4つ、端末側が3つ。入口はテイルスケールだけ、そして鍵で入る。ポートは開けず、パスワードは使わない。最後に、頼んで、切って、あとで確認。ティーマックスがあるので、移動中もAIは働き続けます。 |
