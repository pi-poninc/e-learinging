# 第二の脳の作り方 第5回 つなげる：情報を知識に変える — ナレーション台本

行数（8行）= スライド枚数（8枚）に一致させること。

| # | スライド | ナレーション |
|---|---|---|
| 1 | タイトル | 第5回です。今日は、つなげる、です。集めた情報を、自分の言葉にして、リンクで結び、知識に変えていきます。 |
| 2 | 情報と知識 | 情報と知識は、違います。記事やメモは、他人の言葉の、情報です。それを、自分の言葉で言い直して、はじめて、知識になる。その知識を残すのが、パーマネントノート。ずっと使える、あなた自身のノートです。 |
| 3 | 型 | パーマネントノートの型は、4つの問いに答えるだけです。一つ、一言でいうと。要するに何か、を1、2行で。二つ、自分の言葉で。なぜ、どういう仕組みか、を説明する。三つ、具体例。実際の場面を1つ。四つ、関連ノート。他のノートへ、リンクでつなぐ。この4つを埋めるだけです。 |
| 4 | 1ノート1テーマ | コツは、1ノート1テーマ。1枚に、1つの考えだけ書きます。あれこれ詰め込まない。ノートは小さいほど、他のノートとつなぎやすくなります。タイトルは、こういうものだ、という主張の形にすると、後で探しやすいです。 |
| 5 | リンク | つなぐのが、リンクです。関連する言葉を、二重のカッコで囲むだけで、リンクになります。リンクをたどると、関連する知識が、芋づる式に出てくる。さらに、バックリンクという機能で、どのノートから参照されているかも、分かります。 |
| 6 | グラフ | つながりは、目で見ることもできます。グラフビューという機能です。ノートを点、リンクを線として、知識の全体を地図のように表示します。よくつながっている点は、あなたの関心の中心。ぽつんと孤立した点は、つなぎ先を探すヒントになります。 |
| 7 | やってみよう | では、今週、1枚だけ書いてみましょう。インボックスのメモから1つ選び、自分の言葉で言い直す。さっきの4つの問い、一言、説明、例、関連、に答える。そして、関連する言葉を、リンクでつなぐ。たった1枚で大丈夫です。 |
| 8 | まとめ | 第5回のまとめです。情報を、自分の言葉にして、パーマネントノートにすると、知識になる。1ノート1テーマで、小さく分ける。そして、リンクで結び、グラフで全体を俯瞰する。ここまでで、手で育てる第二の脳は完成です。次回は、エーアイで、これを生きた脳にします。 |
