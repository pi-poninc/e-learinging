# 第2回 交流・周波数・単相と三相 — ナレーション台本

|---|---|---|
| 1 | タイトル | 工場の電気設備入門、第2回です。今回は、交流と周波数、そして単相と三相です。工場では、三相を動力、単相を電灯と呼び分けます。ここを取り違えると機械が壊れるので、しっかり押さえましょう。 |
| 2 | 直流と交流 | まず、電気には直流と交流があります。直流は、一方向に流れ続ける電気で、電池やUSB、パソコンの内部、ロボットの制御回路などがこれです。交流は、向きが周期的に入れ替わる電気で、電力会社から来る電気はすべて交流です。交流の利点は、変圧器で電圧を簡単に上げ下げできることです。 |
| 3 | 周波数 | 交流が一秒間に向きを入れ替える回数を、周波数といいます。日本は、静岡の富士川と新潟の糸魚川あたりを境に、東が五十ヘルツ、西が六十ヘルツに分かれています。大阪をはじめ西日本は六十ヘルツ地域です。東京、五十ヘルツで検証した機器を持ち込むときは、銘板に五十六十両対応と書いてあるかを確認してください。電源に直結するモーターは、六十ヘルツだと回転数が約一・二倍になる点にも注意です。 |
| 4 | 単相と三相 | では、単相と三相を整理します。単相、いちファイは、一つの波の交流で、百ボルトや二百ボルト。電線は二本か三本で、照明やコンセント、パソコンに使います。三相、さんファイは、タイミングが三分の一ずつずれた三つの波の交流で、二百ボルト。電線は三本で、モーターや大型機械に使います。そして、三相は家庭にはありません。工場や店舗、ビルだけのものです。 |
| 5 | なぜ三相か | なぜ工場はわざわざ三相を使うのか。利点は三つあります。一つ目、モーターが自然に回る。三つの波が順番に強くなるので、つなぐだけで回転する磁界ができ、構造が単純で丈夫になります。二つ目、力が途切れない。三つの波の合計がいつも一定なので、大きな力をなめらかに出せます。三つ目、電線が少なくて済む。そして、計算に出てくる√3、約一・七三二は、三相の計算には一・七三二を掛ける、とだけ覚えれば実務は足ります。 |
| 6 | 図面の表記 | 図面や見積書では、相、線の本数、電圧がセットで書かれます。三ファイ三ダブリュー六千六百ボルトは、電力会社から工場に来る高圧の受電。三ファイ三ダブリュー二百ボルトは動力、モーター用です。一ファイ三ダブリュー百二百ボルトは電灯で、百ボルトと二百ボルトの両方が取れます。一ファイ二ダブリュー百ボルトは、普通のコンセント、小型機器用です。 |
| 7 | 200Vは2種類 | ここで、現場で一番多い勘違いをお伝えします。二百ボルトは、二種類あります。単相二百ボルトと三相二百ボルトは、電圧の数字は同じでも、別の電気です。単相二百ボルトの機器、たとえば大型のGPUワークステーションは電灯側に。三相二百ボルトの機器、モーターやロボットコントローラーの多くは動力側につなぎます。逆につなぐと、動かないか、壊れます。機器を選ぶときは、銘板の電源欄で、相、電圧、周波数、容量の四つを必ず確認してください。 |
| 8 | まとめ | 第2回のまとめです。電力会社から来るのは交流で、西日本は六十ヘルツ。動力は三相、電灯は単相で、三相の計算には一・七三二を掛ける。そして二百ボルトには単相と三相の二種類があり、逆につなぐと壊れる。ここまでが電気の基礎編です。次回からは、その電気が工場にどう届くか、受電の話に入ります。 |
