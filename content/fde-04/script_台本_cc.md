# FDEスクール 第4話「社長への月次報告」台本

| # | スライド | ナレーション |
|---|---|---|
| 1 | タイトル「社長への月次報告」/ 第4話 | FDEスクール第4話、「社長への月次報告」。月額を続けてもらうための、一番大事な装置の話です。 |
| 2 | 狙い / 社長が「来月も払う理由」を毎月感じる | 狙いは、社長が毎月「来月も払う理由」を感じること。そのために、責任者が社長と直接、月に一度向き合います。 |
| 3 | 1枚フォーマット / 全体像 | 報告はたった1枚にまとめます。中身は4つ。順番に見ていきましょう。 |
| 4 | ① 今月やったこと | 1つ目、今月やったこと。動いたもの、消化した課題を、具体的に。 |
| 5 | ② 数字 | 2つ目、数字。課題の消化数、利用状況、効果。製品なら利用ダッシュボードを見せます。 |
| 6 | ③ 来月の5つ | 3つ目、来月の5つ。更新した課題一覧の、上位5件です。 |
| 7 | ④ リスク / 判断してほしいこと | 4つ目、リスクと、社長に判断してほしいこと。ここは1つか2つに絞ります。 |
| 8 | ONS例 / ステコミ報告会がこの装置 | 大阪鉛さんでは、ステコミ報告会や定例が、まさにこの装置になっています。アジェンダはドキュメントで管理します。 |
| 9 | まとめ / 次回「第5話 共通の道具」 | この1枚を毎月回せば、関係は続きます。次回は第5話、「共通の道具」。人貸しに戻らないための仕組みです。 |
