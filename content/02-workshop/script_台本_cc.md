# 顧客ワークショップを「翌日の意思決定」に変える — ナレーション台本（丁寧版）

行数（12行）= スライド枚数（12枚）に一致させること。

| # | スライド | ナレーション |
|---|---|---|
| 1 | タイトル | それではここから、新入社員のみなさんに向けて、顧客ワークショップの回し方についてお話しします。今日のテーマは、会議に出るだけで終わらせない、です。ワークショップを、翌日から動ける意思決定に変えるやり方を、順番に見ていきましょう。 |
| 2 | 問題提起 | まず、よくある失敗から入りましょう。会議に出て、議事録もちゃんと残した。それなのに、翌日になると誰も動いていない。決めたつもりだったのに、実は何も決まっていない。そして次の会議で、また、で、結局どうする、が繰り返される。こういう会議、心当たりありませんか。今日は、これを防ぐ型をお伝えします。 |
| 3 | 実例の紹介 | 今日は、実際の案件を例にします。ジャーメックとキャミックの、遠隔読影ワークショップです。これは、動物病院の遠隔読影、つまり離れた場所から画像を診断する仕組みを、新しいシステムでどう回すかを設計する会です。論点は、運用のルール、例外の処理、そしてレポートの入力方法。ここが曖昧なままだと、システムの実装で必ず詰まります。 |
| 4 | 全体像 | この日、私たちがやったことを、三つの原則に整理しました。原則の一つ目は、曖昧な運用を構造に落とすこと。二つ目は、決定、未決、次のアクションを分けること。三つ目は、エーアイに整理させて、人は削る、判断することに集中すること。ひとつずつ、具体的に見ていきます。 |
| 5 | 原則①レーン | 一つ目の原則、その一です。曖昧な運用は、レーンで分けます。たとえば遠隔読影の例外を、三つのレーンに分けました。緊急・急ぎ、情報不足、そして想定外の所見、の三つです。こうしてレーンごとに対応の方針を決めておくと、現場の人が、これはどのケースだ、と迷わなくなります。 |
| 6 | 原則①階層 | 一つ目の原則、その二です。さらに、階層で段階に分けます。レポートの入力を、三つの階層に分けました。迷わず決まる部分は自動入力、選べば済む部分は選択と定型文、そして判断が要る部分だけを自由記載にします。ポイントは、全部を自由記載にしないこと。こうすると、入力が速くなり、書き方のばらつきも減ります。 |
| 7 | 原則①まとめ | ここまでをまとめます。レーンは分類、階層は段階です。曖昧でなかなか決まらないものは、分類か段階のどちらかに分けてみると、ぐっと決まりやすくなります。コツは、中身を議論する前に、まず、どう分けるか、を先に決めることです。 |
| 8 | 原則② | 二つ目の原則です。決定、未決、次のアクションを、はっきり分けます。決定は、もう動かしていいこと。未決は、誰が、いつまでに決めるか。次のアクションは、誰が、何をやるか。この三つを、ぜんぶ混ざった議事録にしないこと。分けるだけで、翌日の動きがまったく変わります。 |
| 9 | 原則②共有 | そして、その日のうちに共有します。鮮度が価値です。翌日になると、記憶も、その場の熱量も薄れてしまいます。完璧な議事録を作るより、動ける一枚を先に出す。未決の項目は、宙ぶらりんにせず、必ず担当と期限をつけて渡しましょう。 |
| 10 | 原則③ | 三つ目の原則です。エーアイに整理させて、人は削る、判断する、に集中します。生の議事メモは、まずエーアイに渡して構造化させます。そのうえで、人が、要らない所を削り、重要なところを判断します。完璧な記録を目指すのではなく、次に動ける要点に寄せていく。これが、速くて質の高いやり方です。 |
| 11 | 手順 | では、明日から自分の会議で回すための手順です。まず、現場と論点をよく観察する。次に、レーンや階層で構造化する。そして、決定、未決、次のアクションに分ける。最後に、その日のうちに共有する。この四つのステップを、まずは一回、自分の会議でやってみてください。 |
| 12 | 学び | 最後に、これだけは覚えてください。会議の成果は、議事録ではなく、次に動ける状態です。出て終わりにしない。曖昧な業務は、レーンや階層に分けて構造化する。そして、決定、未決、次のアクションを分けて、その日のうちに共有する。これができれば、あなたの参加する会議は、ぐっと価値のあるものに変わります。 |
