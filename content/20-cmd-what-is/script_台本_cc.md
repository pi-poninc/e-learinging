# はじめてのGitとコマンド 第1回 コマンドとは — ナレーション台本

行数（7行）= スライド枚数（7枚）に一致させること。

| # | スライド | ナレーション |
|---|---|---|
| 1 | タイトル | はじめてのGitとコマンド、第1回を始めます。この講座は、パソコンの黒い画面、いわゆるコマンドやGitが、まったく初めてという方のための入門です。専門用語はできるだけ使わず、ゆっくり進みます。黒い画面が怖くなくなる、をゴールにしましょう。 |
| 2 | コマンドとは | まず、コマンドとは何か。ふだん私たちは、アイコンをクリックして、パソコンを操作していますよね。コマンドは、その代わりに、文字で命令を打って操作する方法です。そして、その文字を打ち込む場所が、ターミナル、よく黒い画面と呼ばれるものです。 |
| 3 | なぜ覚える | では、なぜ素人でも覚える価値があるのか。理由は三つ。一つ目、同じ作業を何度もやるとき、クリックよりも速くて正確です。二つ目、やったことを文字で残せるので、他の人も同じことを再現できます。三つ目、そしてこれが大事なのですが、プログラミングや、次回以降に学ぶGitを使うには、コマンドがほぼ必須の入り口になります。 |
| 4 | どこにある | では、そのターミナルはどこにあるのか。マックの場合は、ターミナル、というアプリです。ランチパッドや、スポットライト検索で、ターミナルと打つと見つかります。ウィンドウズの場合は、ターミナル、またはパワーシェルというものを、スタートメニューから探します。開くと、文字が打てる、黒い、あるいは白い画面が出てきます。 |
| 5 | 画面の読み方 | 画面の読み方です。行の先頭に、ドルマークや、パーセント、あるいは不等号のような記号がありますね。これはプロンプトといって、どうぞ入力してください、という合図です。この記号の後ろに、命令、つまりコマンドを打って、エンターキーを押すと、実行されます。すると、その結果が、下に文字で表示されます。なお、この教材では、入力例をドルマークの後ろに書きますが、ドルマーク自体は打たなくて大丈夫です。 |
| 6 | 怖くないコツ | 怖くないコツをお伝えします。コマンドは、ただの文字の命令です。打っただけでは、何も起きません。エンターを押して、初めて実行されます。それに、打ち間違えても、たいていは、そんな命令はありません、と表示されるだけです。いきなり何かを消す系の命令、これは次回以降で説明しますが、そこだけ気をつければ、基本的には安全です。 |
| 7 | まとめ | 第1回のまとめです。コマンドとは、文字でパソコンに命令すること。ターミナル、黒い画面に文字を打って、エンターで実行します。クリックより速く、正確で、手順を残せて、そしてGitの入り口になります。次回は、迷子にならないための、最初の五つのコマンドを覚えましょう。 |
