# eラーニングの作り方 ダイジェスト — 台本

行数（8行）= スライド枚数（8枚）。

| # | スライド | ナレーション |
|---|---|---|
| 1 | タイトル | eラーニングの作り方、ダイジェスト。pipon learning の解説動画を、本人のクローン声で、半自動に量産する。その全体像を短くつかみましょう。 |
| 2 | 全体像 | 作る流れは四つ。スライドと一対一の台本を書き、スライドを生成し、声と文字起こしから動画を合成し、ビメオにあげて講座に登録する。台本とスライドさえ用意すれば、あとはコマンドがやってくれます。 |
| 3 | 台本 | 動画の質は台本で八割決まります。台本は一行が一スライド。行数とスライド枚数は必ず一致させます。話し言葉で、一枚に一メッセージ。最後は覚える三つか四つで締めると記憶に残ります。 |
| 4 | スライド | スライドはパイソンで作ります。共通テンプレートのビルド・デックに、辞書のリストを渡すだけ。型はタイトル、箇条書き、そして二列のテーブル。一枚の要点は三つまでにします。 |
| 5 | 声と合成 | ナレーションは本人のクローン声、フィッシュ・オーディオで生成します。それをウィスパーで文字起こしし、台本と照合して、スライドの切り替えタイミングを自動で推定。背景とテロップ、そして任意でワイプを合成します。 |
| 6 | レイアウト | レイアウトの基本は、スライドを縮小して左上に置くこと。すると右と下に、歪みのない余白が生まれます。右にワイプ、下にテロップ。見出しと重なりません。テロップの背景は、黒のままにしないのがコツです。 |
| 7 | 登録 | 仕上げは、ビルド・コースのコマンド一本。セクションID、並び順、声のモデルIDを渡すと、生成から、ビメオへの限定公開アップロード、レッスン登録まで通ります。時間がかかるので、バックグラウンドで実行します。 |
| 8 | まとめ | 大切なのは四つ。顧客名や数値は必ず一般化する。台本とスライドは一対一。切り替えタイミングはプレビューで目視確認する。そして締めで要点を示す。これを守れば、速く、安全に量産できます。 |
