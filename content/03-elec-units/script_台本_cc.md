# 第1回 電気の単位 — ナレーション台本

行数（8行）= スライド枚数（8枚）に一致させること。

| # | スライド | ナレーション |
|---|---|---|
| 1 | タイトル | 工場の電気設備入門、第1回を始めます。この講座は全10回。大阪鉛様の現場で、電気担当者やベンダーの方と同じ言葉で話せるようになるための、前提知識シリーズです。第1回のテーマは、すべての土台になる、電気の単位です。 |
| 2 | ゴール | まず、この講座のゴールです。工場の電気の話は、単位と用語さえ分かれば、決して怖くありません。読み終えるころには、新しい設備をこの工場に置けるかどうかを、自分で一次確認できるようになります。全10回で、一歩ずつ積み上げていきましょう。 |
| 3 | まず覚える3つ | 細かい話に入る前に、まずこの3つだけ覚えてください。1つ目、キュービクルは、電力会社から六千六百ボルトで受けた電気を、工場で使える二百ボルトや百ボルトに下げる、小さな変電所です。2つ目、三相、さんファイは、モーターを回す電気で、工場では動力と呼びます。3つ目、単相、たんそうは、照明やコンセント用で、電灯と呼びます。 |
| 4 | 5つの単位 | では本題の単位です。工場の電気は、ボルト、アンペア、キロワット、ケーブイエー、キロワットアワーの5つが分かれば、ほぼ追えます。水道にたとえると、ボルトは水圧、アンペアは流れる水の量、キロワットは実際に水車を回している力、ケーブイエーは配管の太さ、つまり器の大きさ、キロワットアワーは使った水の総量です。 |
| 5 | 電圧と電流 | もう少し電圧と電流を見ます。電圧は電気を押し出す力、電流は実際に流れる量です。大事なのは、同じ仕事をさせるなら、電圧を高くすると電流は少なくて済む、ということ。電流が少なければ電線を細くでき、途中の損失も減ります。これが、電気を高い電圧で送って、使う直前で下げる理由です。 |
| 6 | 電力と電力量 | 次に、キロワットとキロワットアワーの違いです。キロワットは、今この瞬間の、使う勢い。キロワットアワーは、その勢いで何時間使ったか、の積み上げです。十キロワットの機械を三時間動かすと、三十キロワットアワー。車でいえば、キロワットは速度計、キロワットアワーは走行距離です。電気料金は、この両方にかかります。 |
| 7 | 力率 | 最初のつまずきどころが、キロワットとケーブイエーの違い、力率です。交流では、流した電気のすべてが仕事になるわけではありません。ケーブイエーは電圧かける電流の、見かけの電力で、電線や変圧器はこの大きさに耐える必要があります。キロワットは、そのうち実際に仕事をした分。その比、キロワット割るケーブイエーが力率で、一に近いほど無駄がありません。ビールのジョッキでいえば、全体がケーブイエー、ビールがキロワット、泡が無駄な電力です。 |
| 8 | まとめ | 第1回のまとめです。単位は、ボルト、アンペア、キロワット、ケーブイエー、キロワットアワーの五つ。キロワットは仕事量、ケーブイエーは器、キロワットアワーは使った量です。力率はキロワット割るケーブイエーで、一に近いほど無駄がありません。次回は、交流と周波数、そして単相と三相、動力と電灯の話に進みます。おつかれさまでした。 |
