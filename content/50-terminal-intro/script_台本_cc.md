# ターミナル入門ダイジェスト — 台本

行数（9行）= スライド枚数（9枚）。

| # | スライド | ナレーション |
|---|---|---|
| 1 | タイトル | ターミナル入門、ダイジェスト。黒い画面を、自分の道具に変えましょう。開き方から安全ルールまで、全体像をざっと掴みます。 |
| 2 | なぜ？ | ターミナルを使う理由です。フォルダ操作などを、1行で速く正確にできる。GitやClaude Codeも、ここから使います。そして、怖くありません。打ったことしか起きないからです。 |
| 3 | 開き方 | まず開きます。Macはターミナル・アプリ、Spotlightで『terminal』。WindowsはPowerShell。開発ではWSLやGit Bashも使います。行の先頭の、パーセントやドル、大なり記号の後ろに打ちます。その前に出ているのが、今いる場所です。 |
| 4 | 迷子3点 | 迷子にならない3つ。ピー・ダブリュー・ディーで、今どこにいるか。エル・エスで、何があるか。シーディーで移動。ドット2つで1つ上、チルダでホームに戻れます。 |
| 5 | 作る・見る・消す | 基本の操作です。エムケー・ディーアイアールでフォルダを作る。タッチ、またはニュー・アイテムでファイルを作る。キャットで中身を見る。アールエムで消す。ただし即削除なので、消す前にエル・エスで確認を。 |
| 6 | 時短 | 速く正確に打つコツ。パスは住所で、チルダはホーム。そしてタブキーで補完。途中まで打ってタブを押すと、打ち間違いが激減します。上キーで、前のコマンドも呼び戻せます。 |
| 7 | 困ったとき | 詰まっても落ち着いて。止めたいときは、コントロール・シー。エラーが出たら、最後の行をよく読む。そして、管理者権限のスードゥーは、意味が分かるまで使わないでください。 |
| 8 | 安全 | 事故を防ぐ型です。アールエム・マイナス・アールエフは最も危険。場所を確認せずに実行しない。コピペしたコマンドは、中身を理解してから。そして、確認、実行、確認のリズムを守りましょう。 |
| 9 | はじめよう | まずは、ピー・ダブリュー・ディーとエル・エス。そして、エムケー・ディーアイアールで、フォルダを1つ作ってみる。黒い画面に慣れたら、次は、GitHubに進みましょう。 |
