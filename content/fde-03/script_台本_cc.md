# FDEスクール 第3話「月額提案の出し方」台本

| # | スライド | ナレーション |
|---|---|---|
| 1 | タイトル「月額提案の出し方」/ 第3話 | FDEスクール第3話、「月額提案の出し方」。課題一覧ができたら、いよいよ月額の提案です。 |
| 2 | 狙い / 範囲固定の請負ではなく「解き続ける」契約に | 狙いは、決まった納品物を納める請負ではなく、課題を毎月解き続ける契約にすること。これが月額の本質です。 |
| 3 | 提案の芯（ひとこと） | お客さまにはこう言います。「決まった納品物ではなく、御社の課題を毎月いちばん効く順に解き続けます」。これが提案の芯です。 |
| 4 | 体制 / 責任者1名が窓口（社長と直接） | 体制はシンプル。責任者が1名、御社の窓口になり、社長と直接話します。その後ろにpiponのチームと共通の道具があります。 |
| 5 | スコープ / 課題一覧をローリングで | スコープは、前回作った課題一覧です。毎月見直して、終わったら次に差し替える。固定しないのがポイントです。 |
| 6 | 料金 / 初期＋月額200〜250万×12ヶ月 | 料金は、立ち上げの初期費用と、月額のリテイナー。目安は月に200万から250万、12ヶ月です。製品の利用料は別建てにします。 |
| 7 | 出口の約束 / 共通の道具で早い・安い・引き継げる | そして出口の約束。共通の道具を使うので、早く、安く、引き継げる。囲い込みではなく、信頼で続けていただく形です。 |
| 8 | 提案書の骨子 | 提案書の骨子は6つ。現状と課題5つ、今月やること、体制と責任者、料金、月次報告の形、再利用する道具。テンプレートがあります。 |
| 9 | まとめ / 次回「第4話 社長への月次報告」 | 提案が通ったら、関係を続ける装置が要ります。次回は第4話、「社長への月次報告」。 |
