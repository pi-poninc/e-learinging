# 実演デモ 録画ガイド（第二の脳）

スライド・ナレーション・テロップ・背景はすべて生成済みです。
**あなたがやることは、Obsidian/Claude Codeの画面を1本録画して、このフォルダに `wipe.mp4` として置くだけ** です。
置いたら教えてください（または `python3 content/finish_sb_demo.py` を実行）。→ 合成→Vimeo→講座に登録まで自動で行います。

## 録画の仕様
- 形式: mp4（QuickTime/画面収録の標準でOK）
- 長さ: **約96秒**（ナレーションに合わせる。多少長い/短いは`-shortest`で自動調整）
- 配置先: `content/47-sb-demo/wipe.mp4`
- 映すもの: Obsidianのウィンドウ（＋STEP6はターミナルのClaude Code）。**ワイプは画面右の余白に縮小表示される**ので、文字が小さすぎないように、ウィンドウはやや大きめ・フォント大きめ推奨。

## 録画台本（ナレーションに合わせて操作）
| 時間 | ナレーション | 画面でやること |
|---|---|---|
| 0:00〜0:09 | 導入 | Vault全体＋7フォルダ（00_Inbox〜90_Archive）が見える状態を映す |
| 0:09〜0:20 | STEP1 ためる | 00_Inboxに新規ノート作成→一行メモを打つ |
| 0:20〜0:33 | STEP2 まわす | 10_Dailyに今日の日付でノート作成→「今日やること」→Top3を書く |
| 0:33〜0:46 | STEP3 つなげる | Inboxのメモを元に、Permanent Noteを作成→一言/説明/例/関連を埋める |
| 0:46〜0:58 | STEP4 結ぶ | 本文で `[[` を打ってリンク候補を出し、リンクを作る→クリックで飛ぶ |
| 0:58〜1:10 | STEP5 俯瞰 | グラフビューを開いて、少しドラッグ/ズームして見せる |
| 1:10〜1:24 | STEP6 生かす | ターミナルで `claude` → `/ask-vault 今週の要点は？` を実行して結果が出る様子 |
| 1:24〜1:36 | まとめ | HOME.md か ダッシュボード.md を開いて締め |

## 注意（機微情報）
- STEP6の `/ask-vault` は実データ（顧客名など）が映る可能性があります。社内教材として問題なければそのまま、避けたい場合は:
  - 安全な問い（例: `/ask-vault 第二の脳の使い方を3行で`）に差し替える、または
  - STEP6を飛ばして録画（その分まとめを長めに）してもOK。合成側は長さを自動調整します。
- 迷ったら、STEP1〜5（手で使う基本ループ）だけでも十分成立します。

## 完璧じゃなくていい
- 噛んでも、間があっても大丈夫。ナレーションは別音声なので、画面は「それっぽく操作している」だけでOK。
- 一発撮りでOK。やり直したいときは録り直して上書きするだけ。
