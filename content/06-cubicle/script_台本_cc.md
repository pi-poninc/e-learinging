# 第4回 キュービクルとは何か — ナレーション台本

行数（8行）= スライド枚数（8枚）に一致させること。

| # | スライド | ナレーション |
|---|---|---|
| 1 | タイトル | 工場の電気設備入門、第4回です。今回は、この講座の主役、キュービクルを詳しく見ていきます。五つの役割と、中に入っている機器を、略号ごと押さえましょう。 |
| 2 | キュービクルとは | キュービクルは、高圧で受けた電気を、安全に受け取り、測り、守り、電圧を下げ、工場内に配るための機器一式を、金属の箱に収めたものです。正式名称は、キュービクル式高圧受電設備。箱に入っているのが名前の由来です。役割は五つ。受ける、測る、守る、下げる、配る。守るというのは、ショートや漏電が起きたら瞬時に電気を遮断することです。なお、古い工場や大きな工場では、箱に入れず電気室に機器を並べる、開放形もありますが、役割は同じです。 |
| 3 | 見た目 | 見た目は、クリーム色や灰色の金属の箱で、大きさは物置から小型コンテナくらい。屋外の敷地の隅や、建屋の屋上、専用の電気室に置かれています。扉には高圧危険、変電設備といった表示があり、施錠されています。近くに立つとブーンという低い音がしますが、これは変圧器の鉄心が振動する音で、正常です。ただし、資格のない人は絶対に扉を開けません。安全については、第9回で詳しくお話しします。 |
| 4 | 中の機器1 | 中の機器を、電気が流れる順に見ます。略号は図面にそのまま出てくるので、略号で覚えるのが実用的です。ピーエーエスは責任分界点の門番で、工場側の事故で自動的に切り離し、波及事故を防ぎます。ディーエス、断路器は、点検のときに回路を目に見える形で切り離すスイッチ。ブイシービー、真空遮断器は、事故のときに大電流を瞬時に切る、高圧のメインブレーカーです。小規模な設備では、その代わりにエルビーエスとヒューズの組み合わせを使います。 |
| 5 | 中の機器2 | 続いて、測る、守る、下げる、配る、を担う機器です。ブイシーティーとダブリューエイチは、取引用のメーター一式で、使用量とデマンド、三十分ごとの値を記録します。オーシーアールやジーアールは、過電流や漏電の見張り役で、異常があればブイシービーに切れと指令します。ティーアール、変圧器は、六千六百ボルトを二百、百ボルトに下げる本体で、キュービクルの心臓部です。そのほか、力率を改善する進相コンデンサや、低圧側のブレーカー、漏電ブレーカーが並びます。 |
| 6 | 変圧器 | 中でも一番大事なのが変圧器です。容量の話はすべて、この変圧器が起点になります。動力用と電灯用は、別の変圧器です。動力用は三相、電灯用は単相で、それぞれに容量、ケーブイエーがあります。容量は五十、百、三百、五百といった規格値から選ばれます。そして変圧器は、何もつながなくても、通電しているだけで少し電気を消費します。古い変圧器ほどこの損失が大きいので、高効率型への更新は、省エネ投資の定番です。 |
| 7 | 形式と寿命 | キュービクルは、高圧側の主遮断装置の種類で二つに分かれます。ブイシービーと継電器を使うシービー形は、保護が確実で、中規模以上の工場はこちら。ヒューズと負荷開閉器を使うピーエフエス形は、構造が簡単で安く、小規模向けです。更新の目安は、変圧器が二十から三十年、遮断器や継電器が十五から二十年ほど。ただし精錬所は、粉じんや腐食性のガス、海に近い立地も多いため、一般の工場より劣化が早い前提で見ておくのが安全です。 |
| 8 | まとめ | 第4回のまとめです。キュービクルは、工場の小さな変電所。役割は、受ける、測る、守る、下げる、配るの五つで、心臓部は変圧器です。中の機器は略号で覚える。動力用と電灯用の変圧器は別で、その容量が、次回以降の判断の起点になります。次回は、この設備を一枚にまとめた図面、単線結線図の読み方です。 |
