# はじめてのGitとコマンド 第6回 困ったとき＆安全のコツ — ナレーション台本

行数（7行）= スライド枚数（7枚）に一致させること。

| # | スライド | ナレーション |
|---|---|---|
| 1 | タイトル | はじめてのGitとコマンド、いよいよ最終回、第6回です。今回は、困ったときの対処と、安全に使うコツ。そして、今日から使える、最小のワークフローをまとめます。ここまで来れば、もう黒い画面は怖くありません。 |
| 2 | status | 困ったら、まず、これです。ギット、ステータス。操作に迷ったら、とにかく、ギット、ステータスと打ちましょう。今、どのファイルが変更されていて、どれがアド済みか、その状況が分かります。ギット、ログで、これまでの保存履歴も確認できます。あわてて操作する前に、まず現在地を見る。このクセをつけてください。 |
| 3 | 気をつける | 次に、気をつけることです。一つ、アールエム、ハイフンアールエフ、のような、まとめて消す命令は、確認せずに使わないでください。これは戻せません。二つ、パスワードや、エーピーアイキーなどの、秘密の情報は、コミットしないこと。公開事故のもとになります。三つ、意味の分からないコマンドを、コピペで、そのまま実行しないこと。少しでも不安な操作は、実行する前に、詳しい人に聞く。これが一番安全です。 |
| 4 | 間違えたとき | でも、安心してください。間違えても、たいていは戻せます。まだコミットしていない変更なら、元に戻すコマンドで戻せますし、ステータスが、その方法を教えてくれます。コミット済みでも、履歴が残っているので、過去の時点に戻れます。こわい操作や、分からないエラーのときは、無理をせず、人に相談しましょう。Gitは、基本的に、やり直せる道具です。 |
| 5 | ワークフロー | では、今日から使う、最小のワークフローです。これだけで回ります。一つ、ギット、クローン、または、イニットで、プロジェクトを用意する。二つ、ファイルを編集する。三つ、ギット、アド、ドット。四つ、ギット、コミット、ハイフンエム、説明。五つ、ギット、プッシュで、クラウドへ送る。そして、次の作業の前には、ギット、プルで、最新にそろえる。この流れを、まず一回、やってみてください。 |
| 6 | 早見表 | よく使うコマンドの早見表です。まずは、この十個から。ピーダブリューディー、エルエス、シーディーで、今どこ、何がある、移動。ギット、ステータスと、ギット、ログで、今の状態と履歴を見る。迷ったら、これです。ギット、アドと、ギット、コミットで、変更を選んで、保存する。そして、ギット、プッシュ、プル、クローンで、送る、受け取る、コピーしてくる。 |
| 7 | まとめ | では、全六回のまとめです。コマンドとは、文字で命令すること。ピーダブリューディー、エルエス、シーディーで、迷子になりません。Gitは、履歴が残って、戻せる仕組み。編集、アド、コミットのくり返しです。そして、GitHubで、プッシュ、プルして共有する。困ったら、ステータス。不安なら、人に聞く。これで、あなたはもう、黒い画面が怖くありません。全六回、本当におつかれさまでした。 |
