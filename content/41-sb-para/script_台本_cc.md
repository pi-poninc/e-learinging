# 第二の脳の作り方 第2回 土台：フォルダ構成 — ナレーション台本

行数（8行）= スライド枚数（8枚）に一致させること。

| # | スライド | ナレーション |
|---|---|---|
| 1 | タイトル | 第2回です。いよいよ手を動かします。今日は土台づくり、フォルダ構成です。迷わない置き場所を、先に決めてしまいましょう。 |
| 2 | なぜフォルダから | メモが散らかる一番の原因は、どこに置くかで毎回迷うことです。最初に置き場所のルールを決めてしまえば、あとは考えずに放り込める。ここでは、世界中で使われている、パラ、という型をベースにします。 |
| 3 | 7つだけ | フォルダは7つだけ。番号をつけて、並び順も固定します。ゼロゼロ・インボックスは、未処理。まず何でもここに。イチゼロ・デイリーは、その日の記録。ニゼロ・プロジェクトは、締切のある仕事。サンゼロ・エリアは、終わりなく続ける担当領域。ヨンゼロ・リソースは、資料や読書メモ。ゴーゼロ・パーマネントノートは、自分の言葉で残す知識。これに、終わったもの置き場、キューゼロ・アーカイブを足して、全部で7つです。 |
| 4 | Projects/Areas | 迷いやすいのが、プロジェクトとエリアの違いです。プロジェクトは、ゴールと締切があるもの。たとえば、この案件を3月に納品する。エリアは、終わりがなく、ずっと続くもの。たとえば、営業、健康、採用。いつか終わるか、で見分けてください。終わるなら、プロジェクトです。 |
| 5 | Resources/Permanent | もう一つ迷いやすいのが、リソースとパーマネントノートの違いです。リソースは、外から集めた素材。記事や資料、データのコピーです。パーマネントノートは、その素材を自分の言葉で噛み砕いた知識。他人の言葉はリソース、自分の言葉はパーマネント、と覚えてください。 |
| 6 | 増やさない | 大事なルールです。フォルダは、むやみに増やさないこと。7つで足ります。迷ったら、いったんインボックスに入れて、後で動かせばいい。深い階層も作らないでください。探すのが大変になります。そして、1つのノートには、1つのテーマだけ書きます。 |
| 7 | やってみよう | では、今日の作業です。5分でできます。オブシディアンで、新しいボールト、つまり保管庫を作る。そこに、さっきの7つのフォルダを、番号つきで作る。中身はまだ空っぽで大丈夫です。今日は、箱を用意するだけ。 |
| 8 | まとめ | 第2回のまとめです。置き場所を、先に決める。パラに、インボックス、デイリー、パーマネントを足した7フォルダ。プロジェクトとエリア、リソースとパーマネントの違いを押さえる。そして、フォルダは増やさず、1ノート1テーマ。次回は、この箱に、ためていく習慣をつくります。 |
