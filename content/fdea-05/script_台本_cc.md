# FDEスクール応用編 第5話 道具を製品に育てる — 台本

行数（8行）= スライド枚数（8枚）。

| # | スライド | ナレーション |
|---|---|---|
| 1 | タイトル | 応用編、第5話、「道具を製品に育てる」。現場から、道具へ、そして製品へ、という話です。 |
| 2 | ねらい | 現場で作ったものを、資産に変える。道具の循環を回すと、会社に資産が積み上がり、育った道具は、製品にもなります。 |
| 3 | 道具化の基準 | 道具化の基準は、2社目で使えるか、です。この顧客専用か、それとも切り出せるか。切り出せるものは、必ず道具として残します。 |
| 4 | 製品候補 | 実例です。現場から生まれた製品には、医療のボイスチャート、社内ポータルの雛形、大阪鉛で作った選別モデルがあります。どれも、特定の現場から始まりました。 |
| 5 | 置き場と再利用 | 置き場と再利用です。piponのイントラ、ギットハブ、そして第二の脳。誰でも見つけて使える状態にする。見つからない道具は、無いのと同じです。 |
| 6 | 製品の売り方 | 製品の売り方は、月額とは別建ての利用料にすること。解き続ける月額と、製品の利用料を分ける。製品が効くほど、両方が伸びていきます。 |
| 7 | 横展開 | そして横展開。1社で作った道具を、次の顧客の入口にする。作った道具が、次の提案の強みになり、この会社じゃないと、を道具が作ります。 |
| 8 | 次回予告 | 次回は最終話、第6話、「つまずきパターンと対処」。FDEが受託に戻る瞬間を知ります。 |
