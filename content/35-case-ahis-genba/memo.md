# メモ：案件追体験 第4章「現場起点の機能設計」動画版

日付: 2026-10-07
出典: 実案件Slackログ（#連携-jarmec-新ahis-spj1開発、9〜10月）の再構成。顧客名・拠点名・個人名は一般化。
対応: 案件シミュレーター第4章（case_ahis_ch4_scenario.json）の動画版。テーマは「紙の困りごとを機能に変える」。

6局面（すべて実際の機能追加が元ネタ）:
1. 持ち物を紙で記録→言葉の説明が大変 → 写真アップで説明を無くす
2. カルテはPCで書けるが現場で書けない → QR読み取り→スマホ入力（動線に合わせる）
3. 過去カルテが見つからない → オーダー種類でフィルタ（見る目的で切り口）
4. 一覧に何を出すか → 体重列（大型犬判定→大型ケージ確保＝行動の起点）
5. 退院にすると会計待ちから消える不具合 → 退院後も会計待ちに残す（業務実態を映す）
6. 現場要求が無限に湧く → マスト/nice-to-haveを分け、回る最小でフィールドテスト、残りは実地で炙り出す

型6か条: 困りごとの形を機能に／体の動線に合わせる／見る目的で切り口／行動の起点でデータ選ぶ／ステータスは業務実態／回る最小でまず出す。
