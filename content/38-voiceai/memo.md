# メモ：案件追体験 番外編「電話×AI（通話の自動記録・要約）」動画版

出典: 実案件Slackログ（#連携-テルコム-hoip-jarmec-voice-chart連携）の再構成。顧客名・個人名・固有名は一般化。
対応: 案件シミュレーター 番外編（case_voiceai_scenario.json）の動画版。

構成（PBX × 音声基盤 × CRM/CTI）:
1. 連携の全体像 → パラメータ一覧＋シーケンス図で3者の認識合わせ（つなぎ目を先に）
2. 処理の起点 → 通話終了イベントのwebhookを起点に履歴作成→書き起こし→要約
3. 要約を本番に出すか → カテゴリ・内容を検証し精度を確かめてからCRM連携
4. 発展機能の線引き → 番号→顧客情報→画面遷移のコア先行、リアルタイム通知活用は追って検討
5. 顧客FB → 現地で実際に電話→実画面まで見せ、UIを触ってもらいWS的にFB
6. 検証番号 → デモ番号で進めつつ実番号を早めに全部もらい本番条件に寄せる

型6か条: つなぎ目を先に噛み合わせ／確実に効く起点を1つ／出力は中身を検証／コア先行・発展は追って／本物の流れでFB／早く本番条件に寄せる。
