# はじめてのGitとコマンド 第2回 最初のコマンド — ナレーション台本

行数（7行）= スライド枚数（7枚）に一致させること。

| # | スライド | ナレーション |
|---|---|---|
| 1 | タイトル | はじめてのGitとコマンド、第2回です。今回は、最初に覚えたい、五つのコマンドです。この五つさえ分かれば、黒い画面の中で、迷子になりません。一緒に手を動かすつもりで聞いてください。 |
| 2 | pwd | 一つ目、ピーダブリューディー。ターミナルの中では、あなたは常に、どこかのフォルダの中に立っています。そこで、ピーダブリューディーと打つと、今いる場所、つまりフォルダの住所が表示されます。もし、あれ、今どこだっけ、と迷ったら、まずこれ。自分がどこにいるかを確認する、基本のコマンドです。 |
| 3 | ls | 二つ目、エルエス。エルエスと打つと、今いるフォルダの中にある、ファイルやフォルダの一覧が表示されます。リストの略です。これは中身を見るだけなので、安全です。さらに、エルエス、ハイフンエルで詳しく、エルエス、ハイフンエーで、隠しファイルまで表示できます。 |
| 4 | cd | 三つ目、シーディー。シーディーのあとにフォルダ名を打つと、その中に入れます。チェンジ、ディレクトリ、の略ですね。そして、シーディー、ドットを二つ打つと、一つ上のフォルダに戻れます。シーディーだけ、またはシーディー、チルダで、自分のホーム、最初の場所に戻れます。中に入って、エルエスで見て、またシーディーで移動する。この繰り返しで、フォルダの中を行き来します。 |
| 5 | mkdir touch | 四つ目と五つ目は、作るコマンドです。エムケーディアイアールのあとに名前を打つと、フォルダが作れます。メイク、ディレクトリの略です。タッチのあとに、名前てんティーエックスティーなどと打つと、空のファイルが作れます。作ったら、エルエスで、ちゃんとできているか、見てみましょう。 |
| 6 | 便利キー | 入力を楽にするコツです。コマンドの形は、命令、オプション、対象、の順です。たとえば、エルエス、ハイフンエル、フォルダ名、という形ですね。そして、二つの便利なキーがあります。タブキーは、途中まで打って押すと、名前を自動で補完してくれます。上向きの矢印キーは、前に打ったコマンドを呼び出せます。これで、打ち直す手間がぐっと減ります。 |
| 7 | まとめ | 第2回のまとめです。ピーダブリューディーで今どこ、エルエスで何がある、シーディーで移動。そして、エムケーディアイアールでフォルダを作る、タッチでファイルを作る。迷ったら、ピーダブリューディーとエルエス。タブキーと矢印キーで、入力はとても楽になります。次回からは、いよいよGitの話です。 |
