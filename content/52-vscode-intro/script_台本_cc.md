# VS Code入門ダイジェスト — 台本

行数（9行）= スライド枚数（9枚）。

| # | スライド | ナレーション |
|---|---|---|
| 1 | タイトル | VS Code、入門ダイジェスト。編集も、コマンドも、Gitも、1つの画面で。無料のエディタを、あなたの作業場にする全体像を掴みましょう。 |
| 2 | なに？ | VS Codeは、マイクロソフトが無料で配る、テキストとコードの編集ソフトです。WindowsでもMacでも同じ使い勝手。拡張機能で必要な機能だけ足せて、ターミナルも内蔵、Git連携もできます。 |
| 3 | 導入 | まず、code.visualstudio.comから入れます。拡張機能のジャパニーズ・ランゲージ・パックで日本語化。画面は、左の帯でモードを切り替え、中央で編集、下にターミナル、という作りです。 |
| 4 | 基本 | 基本は、フォルダーを開いて、中のファイルを編集・保存。左にファイル一覧が出ます。保存は、コマンドまたはコントロール・エス。タブで複数のファイルを並べて編集できます。 |
| 5 | 探す・呼ぶ | 探すと呼び出す。コントロールやコマンドのエフで検索、シフトを足すと全体検索。ピーでファイルを名前で開く。そして主役が、コマンド・シフト・ピー、コマンドパレット。迷ったら、まずこれです。 |
| 6 | ターミナル | ターミナルは内蔵されています。コントロール・バッククォートで開くと、今開いているフォルダが、そのまま作業場所。クロードやギットのコマンドを、この画面で実行できます。 |
| 7 | 拡張とGit | 機能を足すのが拡張機能。日本語やプリティアなど、信頼できるものだけ入れましょう。そしてソース管理タブで、変更を見て、コミットして、同期。黒い画面なしで、Gitが使えます。 |
| 8 | 安全 | 安全のために。知らないフォルダを開くと、ワークスペースの信頼という確認が出ます。把握できないものは制限モードのままに。怪しい発行元の拡張は入れない。設定同期で、別のパソコンにも引き継げます。 |
| 9 | 覚える4つ | 覚えるのは4つ。フォルダを開く、保存する、ターミナルを開く、コマンドパレットで探す。まずこれで、日常の作業は十分回ります。 |
