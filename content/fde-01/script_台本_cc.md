# FDEスクール 第1話「入口の仕事」台本

> スライド番号 × ナレーション（`video-elearning-compose` 用）。約6分。出典 [[FDEの型]]①。

| # | スライド（画面の要点） | ナレーション（肉声） |
|---|---|---|
| 1 | タイトル「入口の仕事」/ FDEスクール 第1話 | FDEスクール第1話、「入口の仕事」。顧客にどうやって入るか、そして一番大事な「入ったあと」の話をします。 |
| 2 | 見出し「狙い」/ 小さく確実に入る → 信頼と情報を得る → 月額へ繋ぐ | 入口の狙いはシンプルです。小さく確実な仕事で現場に入り、信頼と情報を得る。そして必ず、次の月額につなげる。ここで終わらせないのが肝心です。 |
| 3 | 見出し「3つの入口」/ ①研修 ②業務診断 ③小さな自動化 | 入口は3つ。研修。業務診断。そして小さな自動化。どれかから必ず入ります。 |
| 4 | 入口①研修 / 一番入りやすい / ⚠️一発で終わらせない | 1つ目、研修。Claude Code研修などは一番入りやすい入口です。ただし注意。研修だけで終わらせると、ただの単発になります。研修は月額への踏み台だと考えてください。 |
| 5 | 入口②業務診断 / 現場を見て「課題一覧」を作る＝次回へ | 2つ目、業務診断。現場を見て、課題の一覧を作ること自体を小さく受注します。この課題一覧が、次回学ぶ月額提案の燃料になります。 |
| 6 | 入口③小さな自動化 / 2〜4週間で「動くもの」を1つ | 3つ目、小さな自動化。2週間から4週間で、動くものを1つ出します。早く成果を見せることが、信頼の近道です。 |
| 7 | 見出し「入口で必ずやる3つ」/ 訪問する / IT窓口を特定 / 次への橋を架ける | どの入口でも、必ずやることが3つ。現場に訪問する。社内のIT窓口を見つける。そして、次の月額への橋を、最初から意識しておく。 |
| 8 | ONS例 / 伺い書・お弁当の業務システム＋TA選別PoC | 実例です。大阪鉛さんでは、伺い書やお弁当という小さな業務システムで確実に入りつつ、超硬チップの選別という難問のPoCにも取り組みました。簡単な入口と、難しい挑戦、この両方が「この会社じゃないと」を作ります。 |
| 9 | クロージング / 次回「第2話 課題一覧の作り方」 | 入口から入ったら、次は課題を並べます。次回は第2話、「課題一覧の作り方」。月額の燃料をどう作るかを学びます。 |
