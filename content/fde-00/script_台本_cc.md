| 1 | タイトル「FDEとは何か」/ FDEスクール 第0話 / piponロゴ | pipon FDEスクール、第0話。「FDEとは何か」。この回では、私たちが目指す会社の形を、たった3つの違いで説明します。 |
| 2 | 見出し「結論」/ 大きく「受託 → FDE」/ 売上の単位を“案件”から“顧客”へ | 結論から言います。私たちは受託の会社から、FDE、フォワード・デプロイド・エンジニアの会社へ変わります。ひとことで言えば、売上の単位を「案件」から「顧客」に変える、ということです。 |
| 3 | 見出し「なぜ変えるのか」/ 箇条書き: ①ショットで積み上がらない ②採用できない ③何に投資するか決まらない | なぜ変えるのか。今、3つの悩みがあります。案件が単発で終わり、積み上がらない。人を採っても育て切れない。そして、何に投資すべきかが決まらない。この3つは、実は一本の線でつながっています。 |
| 4 | 見出し「FDE企業の3条件」/ 1 顧客単位の月額 / 2 社長と話せる責任者 / 3 共通の道具 | その線がFDEです。FDE企業は、受託会社と3つだけ違います。1つ、売上の単位が案件ではなく、顧客。毎月の継続契約です。2つ、1社に1人、社長と直接話せる責任者がいる。3つ、顧客をまたいで使い回す、共通の道具がある。 |
| 5 | 見出し「3が一番大事」/ 共通の道具＝手順書・Claude Codeスキル・接続部品 / 無いと「人貸し」に戻る | 一番見落とされるのが3つ目、共通の道具です。これが無いと、ただ人を貸すだけの会社に逆戻りします。最初から立派な製品でなくて構いません。案件ごとに残す手順書、Claude Codeのスキル、接続部品の集まりで十分です。 |
| 6 | 見出し「月額だと何が変わるか」/ 比較: 単発請負 ↔ 月額継続 / 継続売上・粗利・採用計画が立つ | 月額になると何が変わるか。単発の請負では、毎月ゼロから営業です。月額なら、継続する売上が土台になり、粗利が見え、だから人を採る計画が立つ。さっきの3つの悩みが、順番に解けていきます。 |
| 7 | 見出し「最初の実例: 大阪鉛（ONS）」/ 入口=業務システム＋選別PoC → 複数テーマ → 常駐 | 私たちには、すでに最初の実例があります。大阪鉛さん、ONSです。伺い書やお弁当の小さな業務システムという入口から入り、超硬チップの選別という難問にも取り組み、気づけば複数のテーマで、現場に入り込んでいます。これがFDEの入り方です。 |
| 8 | 見出し「この後の学び方」/ 型の4点: 入口 / 課題一覧 / 月額提案 / 月次報告 | 次回からは、この入り方を「型」として学びます。型は4つ。入口の仕事、課題一覧の作り方、月額提案の出し方、そして社長への月次報告。この4つを覚えれば、どの顧客でも同じように入り込めます。 |
| 9 | 見出し「大事な一言」/ 「決まった納品物を納めるのではなく、御社の課題を毎月いちばん効く順に解き続ける」 | 最後に、お客さまへの一言を覚えてください。「決まった納品物を納めるのではなく、御社の課題を、毎月いちばん効く順に解き続けます」。これがFDEの約束です。 |
